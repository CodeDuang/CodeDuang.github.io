# 1.第1集:社交app

a.单词英译中

| 英语            | 中意                     |
| --------------- | ------------------------ |
| DM              | v.私信（Direct Message） |
| text him        | 给他发消息               |
| Awesome         | 太棒了                   |
| QR code         | 二维码                   |
| profile picture | 头像                     |

b.对话中译英：0:48~1:15

对话英译中：10:08~10:37

c.在社交网站上的活动可用做某事 on 某个 app 来表达

请翻译:

- 我能关注你微博吗？（提示：fallow）

- 我能给你发抖音私信吗？

- 我能加你QQ吗？（提示：add）

- 我们能加个微信吗？（提示：与上同）

d.翻译：那么算了（前言：我想加A微信，但A说自己没有微信，我的回应）

那么：then

算了：never mind

英语喜欢先讲重点(先说never mind)

e.立刻马上就做某事，可以用will(将要) 做某事 right now(立刻)

请翻译：

- 我现在就下载微信

- 我现在就给他发消息

- 我现在就做(do it)

- 我现在就把照片发你（提示：send）

- 我现在就付钱给你（提示：pay you）

f.主动提出：让我来做某事，可以用 Let me 加动词原形

请翻译：

- 我来帮你吧

- 我来开门吧（提示：open the door）

- 我来搬吧（提示：carry it）

- 我来扫你微信吧（提示：QR code）

g.翻译：你的头像真的很酷（提示：really cool）

c.想告诉别人你听说来的消息，可以使用i heard（听说这个行为是之前从别人那里听到的消息，所以用过去式），后面接听说的那件事
